## About

I’m Vinay, a full stack developer and B.Tech Computer Science & Engineering student at Kanpur Institute of Technology. I like turning practical ideas into web applications—from responsive React interfaces and backend APIs to database-backed features, authentication, and AI-assisted workflows.

Currently, I’m building **AVONEX**, a ride-sharing platform. I’m also interested in web development, AI-powered applications, and data structures and algorithms.

Building a platform to connect passengers and drivers, with separate passenger and driver workflows.

- Authentication and driver applications with an admin approval workflow
- Ride creation and search, seat booking, and availability management

`React` `Vite` `Node.js` `Express` `MongoDB` `JWT`
